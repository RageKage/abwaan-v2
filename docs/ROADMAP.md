# Abwaan Roadmap

This roadmap consolidates the existing plans into one list with clear priorities.

## Now (Stability + Safety)
- Implement moderation gating (only `published` visible to public)
- Persist reports and create a basic review queue
- Harden Firestore rules to protect system fields (votes/status)
- Finalize deletion flow (soft delete vs hard delete decision)

## Next (UX + Discovery)
- Profile upgrades: show "My Submissions" and add contribution stats
- Author linking from submission cards to public profiles
- Submission editing for owners (with audit timestamps)
- Search UX enhancements (highlight match, show reason badges)
- Improve empty states and action feedback

## Later (Expansion)
- Thematic tags and deeper metadata
- Audio recitations and media support
- Collections and favorites
- Comments and discussion threads
- Multi-language expansion beyond `so` and `en`

## Content Pipeline
- Import the existing archive (300+ proverbs)
- Translate and annotate 100+ raw poems
