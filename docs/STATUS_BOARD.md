# Abwaan Status Board (Draft)

Date: 2026-01-03
Status: Beta

## Where We Started
Abwaan began as a personal rescue mission for Somali proverbs and poetry disappearing inside fast-moving social feeds.

## Where We Are Now (v2 Beta)
- A working archive where anyone can browse entries, search, and filter by type and language
- Accounts support email/password and Google sign-in
- New users claim a unique username during onboarding
- Profiles support display name + bio, and public profiles show contributions
- Submissions include type, language, origin, meaning, translation, and optional sources
- Voting is live for signed-in users; scores update in real time
- Pagination works across archive and profiles
- The Swiss Grid design system is applied across major pages

## What We Plan to Add Next
- Import the larger proverb archive (300+ already collected)
- Translate and add context for 100+ raw poems
- Add a moderation flow (review, approve, hide) before publishing
- Add submission editing and a real report workflow
- Improve discovery: tags, collections, and stronger search

## Content Note
We already have 300+ proverbs archived from online sources and at least 100 poems captured in raw form without translation or context. Turning these into complete, searchable entries is part of the upcoming work.
